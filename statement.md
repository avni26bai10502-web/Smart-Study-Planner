# Smart Study Planner - Project Statement

## Problem Statement

Students often manage their academic tasks, subjects, deadlines, and study time using notebooks or different applications. This can make it difficult to keep track of pending work and understand overall study progress.

The Smart Study Planner is a Python-based application designed to provide a simple centralized system for managing subjects, academic tasks, study sessions, and progress.

## Project Scope

The project includes subject management, task management, study session management, progress tracking, input validation, and report generation.

The current version is a command-line application using Python and SQLite.

## Target Users

The main target users are students who want to organize their academic tasks and monitor their study progress.

## High-Level Features

1. Subject Management
2. Task Management
3. Study Session Management
4. Progress Tracking
5. Report Generation
6. Input Validation
7. SQLite Database Storage
